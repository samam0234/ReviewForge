# 점수 계산 명세

ReviewForge 가 내놓는 모든 수치(가짜 확률·판정 확신도·라벨·대시보드 통계)의 계산 규칙입니다.
코드 기준: [`ai-server/ml/scoring.py`](../../ai-server/ml/scoring.py), [`backend/.../dto/AnalysisDtos.java`](../../backend/src/main/java/com/reviewforge/dto/AnalysisDtos.java) 의 `AnalysisStats`.

## 1. 기호

| 기호 | 의미 | 범위 |
|------|------|------|
| `m` | 모델 확률 (텍스트: fastText 분류기, 이미지: EfficientNet-B3) | 0~1 |
| `r` | 규칙 점수 = 적중한 규칙 가중치 합, 1 에서 자름 | 0~1 |
| `t` | 텍스트 가짜 확률 | 0~1 |
| `i` | 이미지 가짜 확률 | 0~1 |
| `p` | 최종 가짜 확률 (`fakeProbability`) | 0~1 |

## 2. 하이브리드 (텍스트·이미지 공통)

| 상황 | 식 | 비고 |
|------|----|------|
| 모델 있음 | `0.7 · m + 0.3 · r` | `ML_WEIGHT = 0.7` |
| 모델 없음 | `0.1 + 0.8 · r` | 규칙만으로 0.1~0.9 에 매핑 — 0 이나 1 로 단정하지 않음 |

이미지 모델은 **학습된 체크포인트(`image_model.pt`)가 있을 때만** 쓴다. 분류 헤드가 학습되지 않은 EfficientNet-B3 의 출력은 의미가 없기 때문이다.

## 3. 텍스트 + 이미지 융합

```
p = max(t, (1 − w) · t + w · i)
w = 0.30  (이미지 모델 학습됨)
w = 0.15  (이미지 규칙만)
```

- 사진은 의심을 **올리기만** 한다. 사진이 멀쩡해도 과장·홍보 문구 같은 텍스트 조작 신호는 사라지지 않기 때문이다.
- 규칙만 있을 때는 근거가 약하므로 비중을 절반으로 낮춘다.

| 예시 | t | i | w | p |
|------|---|---|---|---|
| 과장 리뷰 + 단색 배경 사진 | 0.912 | 0.42 | 0.15 | **0.912** (i < t → 그대로) |
| 구체적 리뷰 + 일반 사진 | 0.0903 | 0.18 | 0.15 | 0.85·0.0903 + 0.15·0.18 = **0.1038** |
| 구체적 리뷰 + 의심 사진 | 0.2 | 0.9 | 0.30 | 0.7·0.2 + 0.3·0.9 = **0.41** → Suspicious |

(첫 두 줄은 E2E 에서 실제로 나온 값이다.)

## 4. 반올림과 라벨

1. `p` 를 0~1 로 자른 뒤 **소수 4자리로 반올림**한다.
2. 반올림된 `p` 하나로 확신도와 라벨을 함께 계산한다 → 화면에 보이는 수치끼리 어긋나지 않는다.

| 항목 | 식 |
|------|----|
| 판정 확신도 `confidenceScore` | `max(p, 1 − p) × 100` 을 **사사오입**한 정수 |
| 라벨 `label` | `p < 0.4` Genuine · `0.4 ≤ p < 0.7` Suspicious · `p ≥ 0.7` Fake |

- 파이썬 `round()` 는 은행가 반올림이라 `82.5 → 82` 가 된다. ReviewForge 는 `floor(x + 0.5)` 로 `82.5 → 83` 을 쓴다 (v1.1 정정).
- 경계값 예: `summarize(0.69996)` → `p = 0.7`, 확신도 70, 라벨 **Fake**.

> 확신도는 "얼마나 한쪽으로 확실한가" 이지 "리뷰를 믿을 수 있는가" 가 아니다. `p = 0.03` 과 `p = 0.97` 은 둘 다 확신도 97 이다.

## 5. 대시보드 통계 (`GET /api/analyses/stats`)

MongoDB 에서 `userId` 로 거른 뒤 라벨별로 `count`, `Σp`, `Σconfidence`, 사진 포함 건수를 한 번에 집계하고, 백엔드가 합친다.

```
total            = Σ count
avgFakeProbability = (Σ 라벨별 Σp) / total           → 소수 4자리, HALF_UP
avgConfidenceScore = (Σ 라벨별 Σconfidence) / total  → 소수 1자리, HALF_UP
```

- **가중 평균**이다. 라벨별 평균을 다시 평균하면 건수가 적은 라벨이 과대 반영된다
  (예: Genuine 3건 Σp=0.3, Fake 1건 Σp=0.9 → 가중 평균 0.3, 단순 평균의 평균 0.5).
- **전체 기록 기준**이다. v1.0 대시보드는 최근 20건만으로 평균을 냈다.
- 기록이 0건이면 평균은 0, 라벨 건수는 세 라벨 모두 0 으로 채운다.
- 화면에서는 `avgFakeProbability × 100`, `avgConfidenceScore` 를 정수로 반올림해 보여 준다.

## 6. 학습 평가 지표 (`metrics.json`, `image_metrics.json`)

| 지표 | 계산 |
|------|------|
| accuracy / precision / recall / f1 | 임계값 0.5 기준 혼동행렬(`confusion`: tp·fp·fn·tn)에서 계산 |
| roc_auc | Mann-Whitney U: 양성·음성 쌍 중 양성 점수가 더 큰 비율, 동점 0.5. 한 클래스만 있으면 `null` |
| pos_weight | `음성 수 / 양성 수` 를 `BCEWithLogitsLoss` 에 넣어 클래스 불균형 보정 |
